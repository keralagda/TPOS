# OPERATIONS RUNBOOK

## Daily

Check system health, failed jobs, payment webhooks, integration errors, incidents, scheduled rollovers and audit anomalies.

## Release

Validate change → approve → snapshot → schedule → stage → rollout → observe → stable/rollback.

## Incident

Detect → acknowledge → assign → mitigate → communicate → resolve → postmortem.

## Tenant

Verify entitlement → flag → mode → data scope → configuration.

## Document

Upload → security → OCR → classification → review → verify → generate/store.

## Integration

Health → credentials → rate limits → failures → retries → reconciliation.

## Rollback

Never improvise state reconstruction. Use verified snapshot/version.

## Postmortem

Root cause, timeline, affected tenants, detection, mitigation, permanent fix, prevention.
