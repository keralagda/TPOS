# TMS / TRAVEL OPERATIONS

## Purpose

Journey and booking execution after commercial intent exists.

## Navigation

Dashboard, Trips, Trip Planner, Bookings, Itineraries, Flights, Hotels, Experiences, Transfers, Documents, Operations, Disruptions, Reports, Settings.

## Trip lifecycle

`PLANNED → BOOKING → CONFIRMATION → PRE_TRAVEL → ACTIVE → COMPLETED → POST_TRIP`

## Booking operations

Every booking component may generate tasks:
flight, hotel, transfer, experience, visa, payment, document.

Task fields:
owner, team, SLA, priority, dueDate, dependency, status.

## Trip command center

Customer, destination, dates, travelers, flights, hotels, transfers, experiences, visa, payments, documents, tasks, disruptions.

## Exception handling

Cancellation, modification, supplier failure, schedule change, payment failure, missing documents, traveler request, disruption.

## Rule

TMS coordinates operational execution; Accounting remains the financial truth.
