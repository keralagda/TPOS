# ERP / OPERATIONS

## Scope

Internal execution across travel business operations.

## Modules

Operations, Booking Operations, Trip Operations, Procurement, Inventory, Products, Contracts, Tasks, Approvals, Workflow, Resources, Vendors, SLA, Documents, Compliance, Branches, Reports.

## Procurement

`Requirement → Supplier Search → Offer → Negotiation → Approval → Purchase/Supplier Booking → Receipt → Invoice → Settlement`

## Inventory

AVAILABLE, HELD, RESERVED, CONFIRMED, SOLD, BLOCKED, EXPIRED.

## Workflow

`Trigger → Condition → Assignment → Action → Approval → Notification → Next State`

## Task lifecycle

OPEN, ASSIGNED, IN_PROGRESS, WAITING, BLOCKED, COMPLETED, CANCELLED.

## Boundary

ERP/TMS executes operations. CRM owns relationships. Accounting owns financial truth.
