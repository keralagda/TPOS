# SECURITY / PRIVACY / COMPLIANCE

## Principles

Least privilege, tenant isolation, secure defaults, auditability, explicit consent, data minimization, secrets protection, secure file handling.

## Documents

Private by default; authorized download endpoints; access logging; malware/quarantine workflow.

## Voice

Raw audio is not stored by default unless explicitly required and consented.

## AI

No unauthorized data access. Prompt/context assembly respects RBAC and data scope.

## Admin

Critical actions require elevated permission, confirmation and audit.

## Secrets

Never place credentials in source, prompts, logs, client bundles or generated markdown intended for builders.
