# RELEASE MANAGEMENT

## Release types

FEATURE, BUGFIX, SECURITY, DATABASE, UI, API, AI, CONTENT, CONFIGURATION, SCHEMA, INTEGRATION, EMERGENCY.

## Release object

releaseId, version, title, description, changeSet, dependencies, migrationPlan, rollbackPlan, environments, targets, schedule, approvals, deploymentState, healthState, owner, risk.

## Release notes

What changed, why, affected users, migration notes, action required, documentation and status.

## Approval

Risk-based approval chains.

## Rollback

Use immutable snapshots and verified rollback procedures.
