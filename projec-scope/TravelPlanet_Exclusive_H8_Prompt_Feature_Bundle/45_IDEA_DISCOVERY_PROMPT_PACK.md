# IDEA DISCOVERY PROMPT PACK

## Prompt A — Product gap discovery

Analyze current user journeys and discover unmet needs. Cluster duplicates and map candidates to existing modules.

## Prompt B — Traveler opportunity discovery

Explore friction across discovery, planning, booking, travel, experience and post-trip memory.

## Prompt C — Travel-agent opportunity discovery

Explore lead intake, requirements, quotation, supplier sourcing, booking, documents, payments and follow-up.

## Prompt D — Operations opportunity discovery

Explore task orchestration, SLA, disruption, supplier coordination and exceptions.

## Prompt E — Enterprise opportunity discovery

Explore tenancy, governance, integrations, security, rollout and analytics.

## Prompt F — AI opportunity discovery

Find tasks where AI can reduce cognitive load without becoming an unauthorized decision maker.

## Prompt G — Voice opportunity discovery

Find high-frequency navigation/search/action intents suitable for VN/VO.

## Prompt H — GEM8 opportunity discovery

Find evidence-backed ways to extend iconic destinations into lesser-known experiences.

## Prompt I — Social8 opportunity discovery

Find opportunities for persistent communities and group-trip formation.

## Prompt J — Revenue opportunity discovery

Find ethical monetization opportunities across subscriptions, commissions, supplier services, premium features, APIs and enterprise services.

## Required output

`IDEA → USER → PROBLEM → EVIDENCE → EXISTING MODULE → CANDIDATE SOLUTION → EXPERIMENT → METRIC → RISK → ADOPTION GATE`
