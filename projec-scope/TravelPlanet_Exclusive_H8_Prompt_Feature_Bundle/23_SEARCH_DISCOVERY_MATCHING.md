# SEARCH / DISCOVERY / MATCHING

## Global search

Unified search across permitted:
pages, customers, leads, bookings, trips, destinations, hotels, experiences, suppliers, documents, circles, discussions, gems, settings.

## Search pipeline

`QUERY → LANGUAGE → NORMALIZE → INTENT → ENTITY → RETRIEVE → FILTER → RANK → LOCALIZE → PRESENT`

## Ranking inputs

Relevance, availability, traveler constraints, freshness, provenance, preferences, commercial rules, quality, distance where authorized, community signals.

## Matching

Traveler ↔ destination, traveler ↔ experience, traveler ↔ circle, supplier ↔ requirement, product ↔ enquiry.

## Rule

Never leak records outside data scope through search.
