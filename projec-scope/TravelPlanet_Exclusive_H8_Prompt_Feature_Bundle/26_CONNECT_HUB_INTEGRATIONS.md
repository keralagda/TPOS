# CONNECT HUB / INTEGRATIONS

## Integration categories

Travel inventory, hotel, flight, maps, payments, communications, accounting, CRM, ERP, storage, AI, analytics, automation.

## Connector lifecycle

`DISCOVER → AUTHORIZE → CONFIGURE → TEST → VERIFY → ENABLE → MONITOR → ROTATE → DISABLE`

## Connector object

provider, capability, environment, credentials reference, scopes, webhook endpoints, rate limits, health, version, owner.

## Candidate connectors

Use only when commercial/API access is actually available. Examples previously considered include travel inventory providers, maps, payment gateways, accounting systems and communication providers.

## Security

Secrets are never embedded in prompts, client bundles or logs.
