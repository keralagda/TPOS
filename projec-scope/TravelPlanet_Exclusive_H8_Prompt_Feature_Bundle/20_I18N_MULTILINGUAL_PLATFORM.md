# MULTILINGUAL PLATFORM

## Canonical locales

`en-IN`, `ml-IN`, `hi-IN`

## Language vs locale

Language controls presentation. Locale also controls currency, number/date/time formatting, timezone, address, phone and measurement conventions.

## User profile

interfaceLocale, contentLocale, helpLocale, communicationLocale, documentLocale, aiLocale, timezone, currency, dateFormat, numberFormat.

## Translate presentation, not business truth

Do not translate:
IDs, UUIDs, enums, API fields, DB columns, routes, permission IDs, roles, events, accounting codes, registry IDs, integration IDs.

## Translation lifecycle

`SOURCE → REQUIRED → AI_TRANSLATED → HUMAN_REVIEW → APPROVED → PUBLISHED`

English changes mark translations stale.

## Terminology

Canonical product names: Travel Planet, Voyage8, VIBE, GEM8, H8, CRM, TMS, ERP, DMS, AI, API.

## Search

Cross-language semantic search with language detection, normalization, multilingual retrieval and localized results.

## Documents

Localized templates and generation.

## SEO

Localized public routes, canonical metadata, hreflang and localized sitemaps.

## Admin

`/admin/localization` with coverage, queue, glossary, memory, quality and analytics.
