# Travel Planet — AI Assistant

## Position

The admin AI Assistant is a first-class service, not a decorative chatbot.

Backbone:
Voyage8 Travel Intelligence + H8 governance.

## Modes

### Chat
Ask operational questions.

### Insights
Proactive analysis of:
- bookings
- revenue
- destinations
- vendors
- offers
- customers
- connector health

### Actions
AI-assisted operational actions.

### Automations
Governed recurring/conditional workflows.

## Skills

- booking summary
- revenue analysis
- customer segmentation
- supplier analysis
- offer discovery
- price anomaly detection
- destination trend analysis
- connector diagnosis
- report generation
- content drafting
- campaign drafting
- operations triage
- itinerary review
- support summarization

## Action governance

Read-only analysis:
may execute automatically.

Low-risk reversible actions:
may prepare drafts.

Consequential actions:
require explicit confirmation.

Examples:
- cancel booking
- issue refund
- change supplier
- modify price
- publish promotion
- send mass customer communication

## AI truth model

AI recommendations are not governed truth.

Use:
REQUEST = intent evidence
DECISION = approval truth
REGISTRY = declared architecture
DB = persisted operational state
CODE = implementation evidence
RUNTIME = observed evidence
KLUE = probabilistic continuity

Never silently mutate governed Registry truth.
